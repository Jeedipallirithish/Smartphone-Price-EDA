# Smartphone Price Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) and Feature Engineering on a smartphone specifications dataset to understand the factors influencing smartphone pricing.

## Objectives

* Analyze smartphone specifications
* Identify important price-driving features
* Perform feature engineering on raw text columns
* Generate business insights from smartphone market data

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Feature Engineering

Extracted features include:

* RAM
* ROM
* Battery Capacity
* Display Size
* Processor Brand
* Camera Specifications
* Smartphone Brand
* Premium Variant Indicators

## Key Findings

* RAM is the strongest predictor of smartphone price.
* Storage capacity strongly influences pricing.
* Camera quality contributes significantly to premium positioning.
* Display quality and size affect smartphone pricing.
* Budget devices generate higher review counts.

## Project Structure

* Univariate Analysis
* Bivariate Analysis
* Multivariate Analysis
